# 1.1.0 发布说明

## 新增

- 手机号快速登录、11 位校验和首次自动注册。
- 用户头像、昵称和带充值流水的教学模拟充值。
- 腾讯地图地址解析、距离排序、驾车/步行导航及无 Key 离线回退。
- 管理端 Qt Charts 7/30 天趋势、站点在线率、设备累计充电统计。
- 新增站点同步创建设备、站点—设备联动、故障桩模拟远程重启及操作日志。
- 用户手机号模糊查询和订单多条件/日期组合筛选。
- 有界线程池多客户端处理，每个任务独立 SQLite 连接。
- 可重复的数据预处理 CSV 和数据质量 JSON 报告。

## 环境与验证

- BitDev：Ubuntu 22.04、Qt 6.2.4、Qt Creator 20.0.1。
- CTest 覆盖协议、业务流程、新增矩阵需求、并发 Socket、界面渲染和数据预处理。
- 负荷预测与智能推荐仍因缺少合格真实数据而关闭。
