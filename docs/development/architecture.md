# 主干架构边界

依赖方向固定为：界面和网关依赖公共接口，领域服务依赖数据访问与外部适配接口，数据访问层依赖 SQLite。界面、分析脚本和外部适配器不得直接写业务表。

三个独立进程分别为 `ev_user_client`、`ev_admin_client` 和 `ev_server`。客户端只维护显示状态，身份、余额、订单状态和权限以服务端提交结果为准。服务端 TCP 帧采用两个大端 32 位字段 `msg_type`、`payload_length`，后接 UTF-8 JSON，默认最大正文 10 MiB。

当前主干只实现可复用基础设施，不声称设计说明书中的完整业务闭环已经完成。会员、知识库与分析数据后续应通过独立迁移扩展；已发布迁移不可改写。
