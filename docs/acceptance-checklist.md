## 构建与启动

- [x] Ubuntu 22.04 中从新目录执行 CMake 配置成功。
- [x] 服务端、用户端、管理端三个程序编译成功。
- [x] 5 个 CTest 测试全部通过。

## 用户业务

- [x] 注册、登录、退出、个人信息和余额查看。
- [x] 11 位手机号校验、首次手机号登录自动注册和再次登录复用用户。
- [x] 头像上传、昵称修改和带流水的教学模拟充值。
- [x] 地址解析、经纬度展示、距离排序、驾车/步行导航及无 Key 离线回退。
- [x] 按关键词、区域、是否空闲查询站点。
- [x] 查看站点详情、充电桩状态、功率和价格。
- [x] 创建、取消、查看预约，15 分钟自动过期。
- [x] 从预约或空闲桩开始模拟充电。
- [x] 实时显示时长、电量、金额并结束结算。
- [x] 查看订单列表和订单明细。

- [x] 站点新增、编辑、启停和状态查看。

- [x] 充电桩新增、编辑、状态和价格方案维护。
- [x] 设备累计充电次数/时长、故障桩远程重启和操作日志。
- [x] 用户查询和启停。
- [x] 用户手机号模糊查询、订单多条件与日期组合筛选。
- [x] 全部预约、充电会话和订单查询。
- [x] 故障登记、处理中和解决状态维护。

## 异常与一致性

- [x] 非法登录返回明确错误。
- [x] 重复预约/同桩并发预约只有一个成功。
- [x] 故障、离线或停用充电桩不能开始充电。
- [x] Socket 粘包、拆包和超限消息有保护。
- [x] 断线、请求超时和服务端异常有界面提示。
- [x] 密码使用随机盐和迭代 SHA-256 摘要保存。
- [x] 日志为 JSON Lines 且不包含密码和令牌。
- [x] 两端在无显示模式完成登录、加载数据、渲染并生成截图。
- [x] 有界线程池异步服务多客户端，每个任务使用独立 SQLite 连接。
- [x] 数据预处理可重复导出 CSV 与质量报告，并有自动测试。
- [x] BitDev 的 Qt Creator 20.0.1 与 Qt 6.2.4 已验证。
