# 第一阶段演示脚本

建议总时长 6–8 分钟。

## 1. 启动（约 1 分钟）

在项目根目录打开三个终端，依次执行：

```bash
./scripts/run_server.sh
./scripts/run_user_client.sh
./scripts/run_admin_client.sh
./scripts/run_dashboard.sh
```

说明两个客户端只通过 TCP Socket 访问服务端，数据库只由服务端写入。

## 2. 用户闭环（约 3 分钟）

1. 用 `demo` 登录用户端。
2. 在“附近站点”按区域或关键字查询，打开一个站点。
3. 选择空闲充电桩并预约。
4. 在“我的预约”展示 15 分钟有效期，然后使用预约开始充电。
5. 展示时长、电量和金额逐秒更新。
6. 结束充电，展示结算订单。
7. 打开“历史订单”，双击订单展示明细。
8. 在“个人中心”展示余额并退出登录。

## 3. 管理端（约 2 分钟）

1. 用 `admin` 登录管理端。
2. 展示用户数、站点数、设备状态、营收和 7 日趋势。
3. 查看刚才产生的预约、充电记录和订单。
4. 新建或编辑价格方案。
5. 把一个空闲充电桩设为故障，回到用户端刷新，证明不可预约。
6. 在“故障”页登记并解决故障，设备恢复空闲。

## 4. 技术与异常（约 1–2 分钟）

1. 展示 `ctest --test-dir build --output-on-failure` 的 3/3 通过结果。
2. 说明 SQLite 使用 WAL、外键、忙等待和 `BEGIN IMMEDIATE` 事务。
3. 说明双客户端同时预约同一充电桩的自动化测试。
4. 停止服务端，展示客户端断线后返回登录页而不崩溃。
5. 说明机器学习依赖真实数据，当前只预留接口，不制作虚假模型。

## 5. 数据大屏（约 1 分钟）

1. 浏览器打开 `http://127.0.0.1:8080`。
2. 点击“生成 30 天演示数据”，说明相同日期重复执行不会重复写入。
3. 展示订单、充电量、营收、设备状态、站点排行和故障趋势。
4. 强调页面和接口均标注“教学演示数据，不代表真实运营结果”。
