================================================================================
  大数据与机器学习 / 模型评估（UML-071，对应 B=71）
================================================================================

  中任务概述：
  本中任务定义预测模型的效果评估机制。模型训练完成后，
  使用测试集评估预测精度；模型上线后，持续对比预测值与
  实际值，监控模型性能是否衰减。评估结果决定是否需要
  重新训练模型或调整参数。

  组件清单（本中任务涉及）：
  - 模型评估模块（ModelEvaluator，Python脚本）
  - 测试数据集（训练时划分的最后10%数据）
  - 预测结果（data/predictions/*.csv）
  - 实际数据（后续产生的真实值，用于回测）
  - 评估报告（data/evaluation/evaluation_report.txt）

  解耦设计：
  - 评估与训练分离：训练负责产出模型，评估负责检验质量
  - 两种评估方式：离线评估（训练时用测试集）+ 在线评估
    （上线后用真实数据回测）
  - 评估结果是模型质量的客观度量，指导模型迭代


------------------------------------------------------------
【UML-071】预测效果评估
------------------------------------------------------------

■ 场景
  模型评估模块对训练好的预测模型进行效果评估，计算各类
  误差指标，生成评估报告。评估分为两个阶段：
    1）离线评估：模型训练完成后，在测试集上评估
    2）在线回测：每日预测结果产生后，与后续的实际值对比
  评估结果用于判断模型是否合格、是否需要重新训练。

■ 参与者
  - 模型评估模块（ModelEvaluator，Python脚本）
  - 测试数据集（测试集序列数据）
  - 预测结果（各预测任务的输出）
  - 实际数据（历史真实值）
  - 评估报告（evaluation_report.txt + evaluation_metrics.csv）

■ 评估指标
  对时序预测模型，使用以下标准评估指标：

  1. MAE（Mean Absolute Error，平均绝对误差）
     MAE = (1/n) × Σ|y_pred - y_true|
     含义：预测值与真实值的绝对差的平均值，单位与目标变量相同
     优点：直观，对异常值不敏感

  2. RMSE（Root Mean Square Error，均方根误差）
     RMSE = sqrt( (1/n) × Σ(y_pred - y_true)² )
     含义：预测误差的标准差，对大误差惩罚更重
     优点：反映误差的离散程度

  3. MAPE（Mean Absolute Percentage Error，平均绝对百分比误差）
     MAPE = (1/n) × Σ|(y_true - y_pred) / y_true| × 100%
     含义：预测误差占真实值的比例，无量纲
     优点：可跨不同量级的序列比较
     注意：y_true为0时无意义，需处理0值

  4. R²（决定系数，Coefficient of Determination）
     R² = 1 - SS_res / SS_tot
     其中 SS_res = Σ(y_true - y_pred)²，
          SS_tot = Σ(y_true - y_mean)²
     含义：模型解释的方差比例
     取值：1.0 = 完美预测，0 = 不比均值好，负数 = 比均值还差

  5. 准确率（Accuracy within tolerance）
     定义：预测值在真实值 ± X% 范围内的比例
     例如：误差在10%以内的预测占比
     优点：业务上容易理解（"X%的预测误差不超过Y%"）

■ 离线评估流程（训练后评估）

  1. 模型评估模块 → 数据存储管理器：加载测试集数据
  2. 模型评估模块 → 数据存储管理器：加载训练好的模型
  3. 模型评估模块 → 模型评估模块：在测试集上执行预测
     - 使用训练集拟合的模型，对测试集做滚动预测
     - 或使用 walk-forward validation（滚动验证）
  4. 模型评估模块 → 模型评估模块：计算各项评估指标
     （MAE, RMSE, MAPE, R², 准确率）
  5. 模型评估模块 → 模型评估模块：与基线模型对比
     - 基线模型：简单移动平均（SMA）或 朴素预测（昨天=今天）
     - 对比指标：模型是否优于基线？优多少？
     - 若模型不如基线，说明模型无价值，需改进
  6. alt 模型指标达标（如 MAPE < 15% 且 R² > 0.7）
     - 模型评估模块 → 模型评估模块：标记模型为"合格"
     - 模型评估模块 → 模型评估模块：生成评估报告
     - 模型评估模块 → 数据存储管理器：保存评估结果
   else 模型指标不达标
     - 模型评估模块 → 模型评估模块：标记模型为"待改进"
     - 模型评估模块 → 模型评估模块：生成评估报告，标注问题
       （如数据量不足、特征不够、模型选择不当）
     - 模型评估模块 → 数据存储管理器：保存评估结果
       （即使不达标也保存，作为迭代依据）
  end

■ 在线回测流程（上线后持续评估）

  1. 每日新数据产生后（数据采集完成后）
  2. 模型评估模块 → 数据存储管理器：加载昨天的预测结果
     （如昨天预测的"今日充电量"）
  3. 模型评估模块 → 数据存储管理器：加载今日的实际充电量
     （从daily_kwh.csv读取）
  4. 模型评估模块 → 模型评估模块：计算单日预测误差
     - 误差 = |实际值 - 预测值|
     - 百分比误差 = 误差 / 实际值 × 100%
  5. 模型评估模块 → 模型评估模块：更新近7日/30日滚动评估指标
     - rolling_mae_7d：近7天平均绝对误差
     - rolling_mape_7d：近7天平均绝对百分比误差
  6. 模型评估模块 → 模型评估模块：检测模型衰减
     - 若近7日MAPE > 训练时测试集MAPE × 1.5
       → 标记"模型可能衰减，建议重新训练"
  7. 模型评估模块 → 数据存储管理器：保存回测结果
     data/evaluation/online_metrics.csv

■ 评估指标阈值（参考）
  - 优秀：MAPE < 10%，R² > 0.9
  - 良好：MAPE 10%~15%，R² 0.8~0.9
  - 合格：MAPE 15%~20%，R² 0.7~0.8
  - 待改进：MAPE > 20% 或 R² < 0.7
  - 不合格：模型不如基线（比简单移动平均还差）

■ 输出
  - data/evaluation/evaluation_report.txt — 评估报告（文本）
  - data/evaluation/evaluation_metrics.csv — 各模型的评估指标
  - data/evaluation/online_metrics.csv — 在线回测滚动指标

■ 关联
  - 前序：UML-066（模型训练，产出模型）
  - 数据输入：UML-061（数据预处理，测试集）、
    UML-067~068（预测结果，在线回测）
  - 后续：
    - 指导 UML-066（模型训练，决定是否需要调整参数重训）
    - 指导 UML-072（模型部署，评估合格才能上线）
  - 说明：
    - 评估是模型质量的"质检"环节
    - 离线评估保证模型上线前的质量底线
    - 在线回测持续监控模型性能，及时发现衰减


------------------------------------------------------------
  模型评估的位置与作用
------------------------------------------------------------

  数据 → 预处理 → 特征工程 → 模型训练 → [模型评估] → 模型部署
                (UML-061)  (UML-065)    (UML-066)    ↑  (UML-072)
                                              │
                                         合格则通过
                                         不合格则返回改进

  在线使用阶段：
  模型部署 → 预测 → 实际数据产生 → [在线回测] → 性能监控

  评估是连接"训练"和"部署"的质量门，
  也是上线后监控模型健康度的持续机制。
